ETERNIA

게임을 먼저 즐기게 하고, 플레이 과정에서 피부 고민과 화장품 선택의 기준을 자연스럽게 경험하게 만드는 액션 RPG.

01 / GAME OVERVIEW

설명하는 게임이 아니라,
선택하게 만드는 게임.

ETERNIA의 정보 전달은 별도의 교육 화면이 아니라 플레이 규칙 자체에 들어갑니다. 필요한 원료를 얻기 위해 보스를 선택하고, 제작하고, NPC의 상황에 맞게 적용하면서 제품 선택의 사고방식을 반복하게 됩니다.

02 / SYSTEM ANALYSIS

기능마다 다른 이유가 있고,
연출도 그 이유를 따라갑니다.

단순 카드 나열 대신 각 시스템의 역할에 맞는 인터랙션을 배치했습니다. 전투는 타깃 스캔, 원료는 분석 패널, 제작은 조합 단계, NPC는 상황 판독처럼 기능과 정보 구조가 애니메이션의 원인이 되도록 설계했습니다.

03 / PROBLEM & VALIDATION

게임의 차별화보다 먼저,
해결할 문제를 검증합니다.

팀 자체 조사에서 확인된 수치는 외부 시장통계와 분리해 표시합니다. 사업계획서의 핵심은 ‘남성 뷰티 시장이 크다’는 주장보다, 실제 타깃이 제품 선택 과정에서 어디에서 이탈하는지에 있습니다.

“무엇을 써야 하는지 모르겠다.”

07 / REALITY CHECK

실제 사업에서 생길 문제까지
웹 안에서 먼저 답합니다.

브랜드 담당자가 가장 먼저 보는 부분은 아이디어보다 실행 리스크입니다. 게임성, 표현 규제, 승인 과정, 개인정보, B2B 제작 범위를 분리해 대응합니다.

RISK / 01

게임성 훼손

뷰티 정보가 전면에 나오면 게임 유입이 약해질 수 있습니다.

→ Steam/PV는 세계관·전투 우선. 뷰티는 플레이 결과로 노출.
RISK / 02

효능 오인

게임 아이템 효과와 실제 화장품 효능을 동일하게 읽히게 해서는 안 됩니다.

→ 실제 제품 정보와 판타지 효과를 UI 레벨에서 분리.
RISK / 03

브랜드 세이프티

캐릭터 표현·퀘스트 문구·원료 정보가 브랜드 이미지와 충돌할 수 있습니다.

→ 기획 → 표현 가이드 → 브랜드 승인 → 공개 게이트.
RISK / 04

개인정보

게임 행동 데이터와 실제 제품 신청 정보는 목적과 권한이 다릅니다.

→ 캠페인 분석은 집계 중심, 개인 연계는 별도 동의.
RISK / 05

B2B 리드타임

큰 커스텀 협업은 개발 일정과 브랜드 승인 일정을 동시에 흔듭니다.

→ 1원료 × 1퀘스트부터 제작 범위를 표준화.
RISK / 06

성과 과장

초기 단계에서 매출 기여를 확정 성과처럼 약속하기 어렵습니다.

→ 도달·시작·완료·상호작용·O2O 퍼널로 계약 KPI 합의.
COMPLIANCE · 실제 브랜드 제품 및 원료를 사용할 경우 화장품 표시·광고 관련 기준과 브랜드 공식 자료를 기준으로 문구를 검수하고, 게임 내 판타지 효과와 실제 제품 정보는 분리해 표시합니다. 개인 식별 정보가 브랜드 또는 제3자와 연계되는 경우에는 별도의 동의와 목적 제한이 필요합니다.

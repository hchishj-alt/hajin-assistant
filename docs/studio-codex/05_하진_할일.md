# 05. 하진이 직접 할 일 (본인 정보·계정이라 AI가 대신 안 함)

## 지금 바로
- [ ] **입금 받을 계좌 넣기**: https://hchishj-alt.github.io/hajin-assistant/studio/#admin → 비밀키 입력 → "손님에게 보이는 계좌"에 은행·계좌번호·예금주(가운데 글자는 *로 가려도 됨) → 저장.
  비밀키는 프로젝트 파일 `hajin-assistant-private/studio/secret.sql` 안 작은따옴표 사이 값. 저장소·채팅에 올리지 말 것.
- [ ] **입금 자동 확인 연결** (관리 화면 맨 아래 "연결 정보 복사"에 주소·헤더가 다 있음)
  - 아이폰: 은행 앱에서 입금 알림을 **문자(SMS)**로 받게 설정 → 단축어 › 자동화 › 메시지 › "입금" 포함 › 바로 실행 → "URL 콘텐츠 가져오기" POST, 본문 `{"p_secret":"비밀키","p_msg":"메시지"}`.
  - 연결 전에는 은행 알림 글을 관리 화면 "입금 알림 붙여 넣기"에 붙이면 같은 방식으로 열림.

## 카드 결제 준비 (코덱스 01번과 같이)
- [ ] 포트원 가입 → 추천패키지로 PG 신청 (사업자등록증, 대표자 신분증, 정산 통장 사본). 신청할 때 **가입비·연회비 면제인지 꼭 확인**.
- [ ] 통신판매업 신고 (간이과세자면 면제. 정부24에서, 수수료 없음, 지역에 따라 등록면허세 연 몇만 원)
- [ ] 카드사 심사 3~4주. 그동안 코덱스가 테스트 모드로 만들어 둠.
- [ ] 승인 후: 포트원 콘솔의 storeId·channelKey(공개 값)를 코덱스에게, API Secret은 Supabase `secrets`에 직접 넣기.

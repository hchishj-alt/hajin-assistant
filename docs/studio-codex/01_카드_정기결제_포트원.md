# 01. 카드 정기결제 붙이기 (포트원 V2)

## 목표
지금은 계좌 이체만 된다. 카드로 **월 2,900원 자동결제**(매달 자동으로 다시 결제)를 붙인다.
이체는 그대로 둔다(카드 없는 사람용). 결제 창에서 "카드로 자동결제 / 계좌 이체" 둘 중 고르게.

## 왜 포트원인가
- 하진 조건: 가입비·연관리비 0원, 건당 수수료만. 토스페이먼츠 직접 가입은 가입비 22만+연관리비 11만이라 탈락.
- 포트원 추천패키지는 PG 가입비·연회비 면제 + 정기결제 지원(포트원 안내 기준). 수수료 카드 3.2~3.4% + 부가세 → 2,900원당 약 105원.
- 실제 PG(KG이니시스, 토스페이먼츠 등)는 포트원 심사 결과로 정해진다. 코드는 포트원 V2 API만 쓰면 PG가 바뀌어도 그대로.

## 먼저 확인할 것 (코덱스가 공식 문서로 확인)
- https://developers.portone.io 의 V2 문서에서: 빌링키 발급(`PortOne.requestIssueBillingKey`), 빌링키 결제(`POST /payments/{paymentId}/billing-key`), 결제 예약 또는 직접 반복 결제, 웹훅 검증, 결제 취소. **아래 이름은 기억에 의존한 것이니 문서와 다르면 문서를 따른다.**
- 포트원 관리자 콘솔의 테스트 채널로 먼저 만든다. storeId·channelKey는 공개 값(화면에 둬도 됨), **API Secret은 Supabase Edge Function 비밀(secrets)에만.**

## 만들 것

### 서버 (supabase/studio.sql에 덧붙임)
- 표 `ps_billing`: token(손님), billing_key(**Edge Function만 읽음**), card_label(예: "신한 1234"), status(active/canceled/failed), next_at(다음 결제일), fail_count, created_at, updated_at.
- 표 `ps_payments`: 모든 결제 기록(수단 card/transfer/usd, 금액, 통화, 외부 결제 id, 상태, 기간 일수). 지금의 `ps_deposits` 매칭분도 마이페이지 결제 내역에 같이 보이게 `ps_mine`을 고친다.
- 기간 늘리기는 기존 규칙과 같게: `paid_until = greatest(coalesce(paid_until, now()), now()) + 31일`.
- 손님용 함수: `ps_card_status(token)`(카드 정보·다음 결제일·해지 여부), `ps_card_cancel(token)`(해지 = 다음 결제부터 안 함, 남은 기간은 유지).
- billing_key는 anon이 절대 못 읽게. 함수 반환값에도 넣지 않는다.

### Edge Function (`supabase/functions/studio-billing/index.ts`, Deno)
- `POST /issue`: 화면에서 받은 billingKey + token → 포트원에 빌링키 조회로 진짜인지 확인 → 첫 결제 2,900원 즉시 청구 → 성공하면 `ps_billing` 저장, 기간 +31일.
- `POST /charge-due`: pg_cron이 하루 한 번 부름. `next_at <= now()`이고 active인 것들을 청구. 실패하면 fail_count+1, 3일 뒤 다시, 3번 실패하면 status=failed(기간은 더 안 늘림).
- `POST /webhook`: 포트원 웹훅 서명 검증 → 결제 상태를 `ps_payments`에 반영(중복 처리 안전하게).
- 비밀: `PORTONE_API_SECRET`, `PORTONE_WEBHOOK_SECRET`, `CRON_SECRET`은 `supabase secrets set`으로만. Supabase 서비스 키는 Edge Function 기본 환경변수 사용.
- pg_cron + pg_net으로 매일 오전 10시(KST) `charge-due` 호출. SQL은 studio.sql에 넣되 CRON_SECRET 값은 넣지 않는다(하진이 따로 실행할 한 줄을 PR에 적는다).

### 화면 (studio/app.js)
- `paySheet`에 맨 위 선택: **카드로 자동결제(추천)** / 계좌 이체.
- 카드: 포트원 브라우저 SDK를 CDN으로 불러 `requestIssueBillingKey` → 성공하면 Edge Function `/issue` 호출 → 결과에 따라 "열렸어요" 처리(지금 이체 성공 화면 재사용).
- 마이페이지 › 구독: 카드면 "신한 1234 · 다음 결제 12월 21일 2,900원", **[해지하기]**(두 번 눌러 확정, "남은 기간은 그대로 쓸 수 있어요"), [카드 바꾸기].
- 결제 실패 시 마이페이지 맨 위에 안내 줄.
- 1년(24,900원) 카드 결제는 한 번 결제(빌링키 없이 일반 결제)로. 자동 연장 없음.

## 끝났다고 볼 기준
- 포트원 **테스트 모드**에서: 카드 등록 → 2,900원 결제 → 잠금 풀림 → `charge-due`를 next_at 지난 상태로 직접 불러 두 번째 결제 → 해지 → 다음 청구 안 됨.
- anon으로 billing_key를 읽을 길이 없음(SQL 시험).
- 이체 흐름은 전과 똑같이 동작.
- PR 설명에: 하진이 할 일(포트원 콘솔 값 넣기, `supabase secrets set`, 함수 배포 명령, cron 한 줄 SQL).

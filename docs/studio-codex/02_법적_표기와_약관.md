# 02. 법적 표기·약관·환불 정책

카드사 심사와 전자상거래법 때문에 필요하다. 하진은 사업자가 있다.

## 만들 것
1. 바닥글(모든 화면 맨 아래)에 사업자 정보: 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처(이메일).
   - **값은 저장소에 쓰지 말고** 서버 `ps_settings`에 넣고(`ps_admin_set` 허용 키를 늘림) `ps_bank`처럼 공개 함수 `ps_biz()`로 읽는다. 관리 화면에 입력 칸 추가.
   - 값이 비어 있으면 그 줄을 숨긴다.
2. `#terms`(이용약관), `#privacy`(개인정보 처리방침), `#refund`(환불 정책) 화면. 마이페이지 › 도움말과 바닥글에서 링크.
   - 디지털 콘텐츠: 결제 후 유료 틀을 한 번도 안 열었으면 7일 안에 전액 환불, 열었으면 환불 없음(이용 시작 전 고지). 정기결제 해지는 언제든, 남은 기간은 유지.
   - 개인정보: 모으는 것은 복구 코드·입금 코드·결제 기록·(카드면) 카드사 이름과 끝 4자리뿐. 이름·전화번호·이메일을 받지 않는다는 점을 분명히.
   - 문구는 초안이다. 화면 맨 위에 "초안"을 달지 말고, PR 설명에 "하진이 법무 확인 필요"라고 적는다.
3. 결제 창의 결제 단추 바로 위에 "구독 내용·환불 정책을 확인했어요" 한 줄과 링크(체크박스까지는 필요 없음, 문구로 고지).
4. 유료 틀을 처음 열 때 `ps_body` 호출 기록이 남게 해서(환불 판단용) 관리 화면에서 "열어 본 적 있음"이 보이게.

## 끝났다고 볼 기준
- 사업자 정보가 비었을 때·찼을 때 둘 다 화면이 깨지지 않음.
- 세 화면이 폰에서 읽기 편함(글자 15px, 줄 간격 1.6 이상).

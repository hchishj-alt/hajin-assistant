# 03. 해외판(영어·달러)

## 결론부터 (11/20 조사)
- Lemon Squeezy는 신규 가입 중단, 2027-03-31 종료 → 쓰지 않는다.
- Polar, Paddle 같은 판매 대행(Merchant of Record)은 건당 약 5% + $0.50 → **$0.99면 절반 이상이 수수료.** 해외판은 **$2.99/월, $24.99/년** (11/21 국내 2,900원에 맞춤).
- 고정비 0원 조건을 지키면서 한국 정산이 되는지 코덱스가 각 서비스 공식 문서로 다시 확인하고 PR 설명에 표로 정리한다. 포트원의 해외 결제(페이팔·엑심베이 등)도 후보.

## 만들 것
1. 언어: 주소 `?lang=en` 또는 브라우저 언어가 한국어가 아니면 영어. 화면 글을 `studio/i18n.js`의 `{ ko: {...}, en: {...} }`로 뺀다. 오른쪽 위에 KO/EN 전환.
2. 틀: `ps_templates.lang = 'en'`인 영어 틀을 따로 둔다(번역이 아니라 영어권에 맞게 새로). 처음엔 무료 5개 + 유료 15개. **본문은 저장소에 넣지 말고** 비공개 SQL로(하진에게 파일로 전달).
3. 결제: 영어 화면에서는 이체 대신 해외 결제 수단 하나. 결제 완료 웹훅 → Edge Function → 같은 `paid_until` 늘리기.
4. 가격 표시는 통화에 맞게(`Intl.NumberFormat`).

## 끝났다고 볼 기준
- 영어로 처음 들어오면 영어 안내·영어 틀·달러 가격. 한국어 화면은 그대로.
- 해외 결제 테스트 모드로 결제 → 잠금 풀림.

# 04. 다듬기 (작은 PR 여러 개로)

우선순위 순서. 하나씩 PR.

1. **만료 알림**: 남은 기간 3일 이하면 목록 화면 맨 위에 얇은 띠("3일 남았어요 · 늘리기"). 끝나면 "구독이 끝났어요".
2. **틀 관리 화면**: `#admin`에 틀 추가·수정·무료 여부 바꾸기(비밀키로 보호, 새 함수 `ps_admin_tpl_save`). 지금은 SQL로만 넣을 수 있다.
3. **많이 쓴 틀**: 복사 횟수를 서버에 모아(`ps_hit(id)`, 손님 구분 없이 숫자만) 목록에 "많이 쓰는" 분류와 카드에 작은 숫자.
4. **보관함 검색**: 마이페이지 보관함 위에 검색 칸(제목·본문).
5. **보관본 내보내기**: 폴더째 .txt로 내려받기.
6. **입금 코드 없이 보낸 입금**: 관리 화면 "못 맞춘 입금"에 같은 금액·비슷한 시각의 결제 창 연 손님 후보를 보여 주기(결제 창을 열 때 `ps_intent(token, plan)` 기록).
7. 오프라인: 목록·무료 틀·보관함을 마지막으로 받은 것으로 보여 주기(서비스 워커 캐시 + localStorage).

각 PR은 README의 시험 방법을 지킨다.

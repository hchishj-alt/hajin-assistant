# 02. 하진이 할 일 (사람 몫)

1. **포트원 가입·심사**: 프롬프트 스튜디오용으로 진행 중인 포트원 계정을 같이 쓰면 된다. 상점이 하나여도 채널은 앱마다 따로 만들 수 있다.
   필요 서류: 사업자등록증, 통장 사본, 신분증, 통신판매업 신고(간이과세자는 면제일 수 있음).
2. 심사가 끝나면 포트원 콘솔에서 **테스트 채널** storeId·channelKey와 API Secret을 코덱스 작업 때 알려 준다(Secret은 채팅·저장소가 아니라 `supabase secrets set`으로만).
3. 코덱스 PR이 오면 PR 설명의 명령 세 개(secrets, functions deploy, cron 한 줄)를 실행한다.
4. 실제 채널로 바꾸는 건 테스트 결제가 다 된 걸 보고 나서.
5. 기프트 키: `/prompter/#/admin`에서 관리 비밀키로 들어가 만든다. 비밀키는 프로젝트 비공개 폴더에 있다.

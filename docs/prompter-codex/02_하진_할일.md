# 02. 실제 결제 열기 — 하진이 할 일 (사람 몫)

코드·서버 보안은 1.9.0에서 다 해 뒀다. 아래는 본인 서류·비밀 값이라 하진만 할 수 있는 것. 위에서부터 순서대로.

## A. 지금 바로 (30분)
1. **사업자 정보 5가지**를 Claude에게 알려 주기: 상호, 대표자, 사업자등록번호, 통신판매업 신고번호(간이과세자면 "면제"), 사업장 주소. 결제 심사 때 사이트 아래에 꼭 보여야 함.
2. **통신판매업 신고**가 아직이면 정부24 "통신판매업 신고"(간이과세자는 면제일 수 있음, 일반과세자는 구매안전서비스 확인증 필요 → 포트원 가입 후 PG사에서 받음).
3. **포트원 가입**: https://admin.portone.io 에서 회원가입 → 결제대행(PG) 통합 신청. 정기결제(빌링) 되는 카드 PG로 신청하고, 가입비·연회비 면제 패키지인지 신청 화면에서 확인. 서류: 사업자등록증, 통장 사본, 대표자 신분증.
   - 심사 사이트 주소: https://hchishj-alt.github.io/hajin-assistant/prompter/ (요금·약관·환불 규정·사업자 정보가 보이는 곳)
   - 상품: 프롬프리에딧 프로, 월 1,990원 정기결제(오픈가, 정가 9,900원)

## B. 포트원 가입되자마자 (심사 기다리는 동안 테스트로)
4. 포트원 콘솔 › 결제 연동 › **테스트** 채널 하나 추가(정기결제 되는 PG의 테스트). 그리고 아래 두 값을 Claude에게 알려 주기 — 공개 값이라 채팅으로 줘도 됨:
   - 상점 아이디 `store-...`
   - 채널 키 `channel-key-...`
5. 비밀 값 3개는 **채팅에 쓰지 말고** Supabase 대시보드 › Edge Functions › Secrets 에 직접 넣기:
   - `PORTONE_API_SECRET` = 포트원 콘솔 › 연동 정보 › V2 API Secret
   - `PORTONE_STORE_ID` = 위 상점 아이디
   - `PORTONE_WEBHOOK_SECRET` = 포트원 콘솔 › 웹훅 설정에서 주소를 `https://wuvqtfvvouweqxbydlqa.supabase.co/functions/v1/prompter-billing/webhook` 로 넣고 나오는 시크릿
   - `CRON_SECRET` = 아무 긴 무작위 글자(비밀번호 생성기로 40자쯤)
6. Supabase SQL Editor에서 한 줄 실행(따옴표 안을 5번의 CRON_SECRET과 같은 값으로):
   `select vault.create_secret('여기에_CRON_SECRET', 'prompter_cron_secret');`
7. Claude에게 "넣었어"라고 말하기 → Claude가 서버 SQL·Edge Function 배포·매일 청구 예약을 하고 테스트 카드로 결제·해지·환불을 돌려 봄.

## C. 심사 통과 뒤
8. 포트원 콘솔에서 **실제** 채널 추가 → 채널 키를 Claude에게 → Claude가 바꿔 끼우고 1,990원 실제 결제 한 번(하진 카드) → 바로 환불로 확인.
9. 환불 요청이 오면: 포트원 콘솔 › 결제 내역 › 취소. 웹훅이 받아서 그 달 기간을 거두고 자동결제를 멈춤(앱에서 따로 할 일 없음).

## 알아 둘 것
- 9,900원 취소선: 실제로 9,900원에 판 적이 없으면 표시광고법상 "허위 할인" 소지가 있음(하진 결정으로 유지 중). 심사에서 지적받으면 "정가" 대신 "오픈가 1,990원"만 남기면 됨(config.js PRICE.list를 0).
- 이미 구독한 사람의 금액은 가격을 바꿔도 그대로(pr_billing.amount). 나중에 올리면 새로 가입하는 사람부터.
- 기프트 키는 그대로 쓸 수 있음.
